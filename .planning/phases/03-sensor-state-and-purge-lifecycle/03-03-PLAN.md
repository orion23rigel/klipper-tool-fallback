<threat_model>
- Threat T-03-06: public purge recursively invokes itself, reports success before
  durable publication, or manual commands bypass authorization. Mitigation: invoke only
  the validated distinct adapter, centralize purge execution, persist before publish,
  reject known-unloaded purge, warn-and-allow unknown authority, and share strict
  selected/inactive command authorization.
- Threat T-03-07: conditional purge duplicates pause/resume, continues printing after
  failure, or publishes a route before purge completion. Mitigation: one guarded
  selection coordinator with explicit existing/owned pause context, exactly-once purge,
  purge before route persistence/resume, and leave every incomplete operation paused.
- Threat: manual extrusion or unrelated scripts silently mark a tool purged. Mitigation:
  only successful internal purge authority or explicit guarded manual mark commands may
  change purge state; add regression tests proving unrelated script activity is inert.
- Threat: Phase 3 falsely claims full safe-transition or timeout behavior. Mitigation:
  leave ROUTE-05 partial, do not implement purge timeout around synchronous scripts,
  and defer heating, full fallback stages, backup traversal, notifications, and
  real-printer UAT.
</threat_model>
