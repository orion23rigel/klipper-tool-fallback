schema-v1 persistence, and all physical workflow boundaries.
</objective>

<threat_model>
- Threat T-05-03: malformed policy, partial reset, or persistence failure publishes
  restart-invalid or partially changed canonical state. Mitigation: validate complete
  normalized operations before candidate creation, preserve strict state invariants,
  build reset-all fully in memory, save once, and publish only after save succeeds.
- Threat: backup policy commands accidentally operate hardware or alter the active
  route. Mitigation: the shared operation path changes only `ToolState.backups`, never
  calls selection, mapping, heater, purge, pause/resume, or workflow resolution code,
  and proves unrelated state preservation.
- Threat: notification re-entry later invokes backup commands. Mitigation: shape the
  command dispatcher so Plan 03 can centrally reject mutation while notification
  delivery is active; this plan does not invoke notification transport.
- Injection-safe notification transport and terminal notification recursion are outside
  this plan; no notification payload or adapter invocation is introduced here.
</threat_model>
