**Step C — Validate tool number format (per D-04, D-05):**

```python
    raise gcmd.error("Tool number must be in format Tn where n is a non-negative integer")
```
This reuses the canonical regex, consistent with how other commands validate tool names.

**Step D — Check if configured (per D-02, DETECT-02):**
```python
if raw_t not in self.config.tools:
    # Undefined tool flow — go to Step E
    ...
```
Check membership in `self.config.tools` (a `MappingProxyType` of configured tool names).

**Step E — Undefined tool: trigger the undefined-tool flow (per D-10, D-11, D-12, DETECT-04):**
When the tool is NOT configured:
1. Log the event: `self.gcode.respond_info("Tool %s is not configured on this printer" % raw_t)`
2. Create a `WorkflowCheckpoint` with `source="undefined_tool"` and `stage="tool_not_configured"` to signal Phase 11. Use `self._workflow_generation` for the generation counter. Include `logical_tool=raw_t` and `current_physical_tool=None` (no physical tool selected yet).
3. Assign it to `self._workflow_checkpoint`.
4. Do NOT pause the print — Phase 11 handles pausing (per D-11).
5. Do NOT call `_guard_workflow_operation()` (per D-17).

Example checkpoint creation:
```python
self._workflow_generation += 1
self._workflow_checkpoint = WorkflowCheckpoint(
    source="undefined_tool",
    stage="tool_not_configured",
    generation=self._workflow_generation,
    logical_tool=raw_t,
    current_physical_tool=None,
    pause_owned=False,
)
```

**Step F — Configured tool: delegate to `_route_logical` (per D-07, D-08, D-09, DETECT-03):**
```python
self._route_logical(raw_t, gcmd)
```
This preserves all existing behavior (mapping lookup, physical selection, purge, etc.) for known tools.

**Step G — Log delegation (per D-09):**
After successful delegation, log: `self.gcode.respond_info("Tool %s is configured; routing normally" % raw_t)`

**Key constraints from CONTEXT.md:**

- D-13: Standalone G-code handler — no monkey-patching.
- D-17: Do NOT call `_guard_workflow_operation()` — tool selection works during workflows.
- D-11: Do NOT pause the print — Phase 11 handles that.
