<threat_model>
- Threat: status output leaks arbitrary file contents or mutates routing state.
  Mitigation: render only the validated in-memory canonical state and keep both status
  interfaces read-only.
- Threat: later lifecycle callbacks observe partially initialized state. Mitigation:
  finalize all prefixed configuration, load/reconcile/persist state, then publish the
  ready state as one ordered operation; fail startup on any error.
- No high-severity threat remains after ordered initialization and read-only output.
</threat_model>
