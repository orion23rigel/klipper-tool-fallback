Create the Klipper extension skeleton, normalized configuration model, and lightweight
test harness that all later Phase 1 work will build on.
</objective>

<threat_model>
- Threat: a user-controlled `state_path` or adapter name produces ambiguous or unsafe
  runtime behavior. Mitigation: normalize paths, reject empty adapter names, and preserve
  all values as data rather than executing them during configuration.
- Threat: invalid or cyclic backup configuration reaches later fallback logic.
  Mitigation: reject invalid names, self references, duplicates, unknown references, and
  invalid timeout/debounce ranges before the printer reaches ready state.
- No high-severity threat remains after these validation controls.
</threat_model>
