<threat_model>
- Threat T-02-05: a transition resumes a pause owned by the user, runs concurrently with
  another transition, or selects hardware through an unauthorized public command.
  Mitigation: distinguish printing from already paused, claim pause ownership only after
  successful configured pause execution, reject reentrancy, call only the private
  physical-selection path, and resume only an extension-owned pause after full success.
- Threat T-02-06: selection, persistence, rollback, or resume failure leaves false routing
  state or continues an unsafe print. Mitigation: publish mapping only after persistence,
  attempt best-effort physical rollback when save fails after selection, report combined
  failures, clear the guard in `finally`, and never resume any incomplete transition.
- Threat: reset publishes inactive identity routes before its active physical transition
  succeeds. Mitigation: construct one complete identity candidate and publish it only
  after the active selection and persistence steps succeed.
- Threat: Phase 2 claims safety from heating, purge, sensor, or fallback behavior it does
  not own. Mitigation: explicitly limit this coordinator to routing transition ownership;
  leave conditional purge to Phase 3 and temperature transfer/stage execution to Phase 4,
  keep ROUTE-05 incomplete until those dependencies integrate with this coordinator, and
  defer real-printer UAT to Phase 5.
- No high-severity threat remains after pause ownership, guarded sequencing, and failure
  containment controls.
</threat_model>
