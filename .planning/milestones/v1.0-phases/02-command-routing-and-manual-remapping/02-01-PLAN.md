Capture configured `Tn` commands transactionally at ready time and establish
recursion-free logical routing through persistent mappings, with trustworthy transient
ownership and status.
</objective>

<threat_model>
- Threat T-02-01: partial or missing handler capture leaves configured commands absent,
  mixed between original and routed behavior, or runtime state partially published.
  Mitigation: capture and install in canonical order as one ready-time transaction,
  restore all originals on every failure path, and publish state/handlers only after the
  complete transaction succeeds.
- Threat T-02-02: routed selection redispatches a public `Tn`, recurses through mappings,
  or supplies misleading logical command identity to a physical macro. Mitigation: invoke
  only saved original callables with a synthetic command representing the mapped physical
  `Tn`; update ownership only after the callable succeeds.
- Threat: transient ownership is mistaken for restart-safe hardware truth. Mitigation:
  keep active logical and selected physical ownership out of schema v1 and initialize both
  as unknown after restart.
- No high-severity threat remains after transactional rollback and direct-call controls.
</threat_model>
